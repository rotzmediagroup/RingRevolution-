# Asset import report — Dumpling Diner sprite sheets

Generated by `tools/asset_import/extract_sheets.py` from the 18 owner-supplied sheets in
`assets/imported/sheets/`. Total: **1251 sprites** in `assets/imported/manifest.json`.

## How to re-run

```bash
python3 tools/asset_import/extract_sheets.py            # full run: sprites, brand, manifest, contact sheets
python3 tools/asset_import/extract_sheets.py --debug    # also writes _debug_*.png (indexed contact sheets + box overlays)
python3 tools/asset_import/extract_sheets.py --only 11 15   # subset (manifest is not rewritten)
```

Requires Python 3.11, Pillow, numpy (scipy is used if present, otherwise a pure-numpy
connected-components fallback runs). Outputs:

- `assets/imported/sprites/<sheetId>/<name>.png` — bbox crop + 4 px transparent padding
- `assets/imported/brand/dumpling_diner_logo.png` — logo from sheet 16 (category `brand`)
- `assets/imported/manifest.json` — id, file, sheet, bbox, size, category, tags, anim, source, license, sha1
- `assets/imported/contact_sheets/<sheetId>.png` — QA sheets with names drawn under each sprite
- `assets/imported/contact_sheets/_report.json` — counts and warnings of the last run

All slicing decisions live in `tools/asset_import/sheets_config.json` (per-sheet regions, method,
names, label exclusions). Change names or boxes there and re-run; the script is idempotent and
clears each sheet's sprite folder first.

## Pipeline

1. Alpha mask at a per-sheet threshold (the sheets carry a wide 1–20 alpha fringe that bridges
   neighbouring sprites, so most sheets use 64–100 for connectivity; crops still keep full alpha).
2. Label removal: (a) solid rounded-rect components with one dominant fill and white/dark text
   (brown `#5a3a28`-ish pills, beige headers), (b) flat dark-brown colour-mask blobs that form a wide
   band with straight edges (catches pills touched by sparkles), (c) loose white caption text,
   (d) config `exclude_rects` / `label_rects`, with `protect_rects` to whitelist sprites.
3. Per-region slicing: `grid` (uniform or explicit bounds, components assigned by centroid so
   petals/sparkles stay with their sprite), `rowbands` (sheet 4), `groups` (animation rows:
   row x anim group x frames, cut at profile valleys with uniform fallback), `cols`, `cc`, `boxes`.
4. Naming from config (`grid_names`, `names`, `row_names`/`group_names`), anim name/frame parsed
   from `<base>_<anim>_fNN`.

## Known issues / things to check

- **Sheet 11 (living foods B)**: several groups in this sheet were drawn with frames physically
  overlapping (no transparent gap). Bounding-box crops cannot separate overlapping art, so a few
  crops include a sliver of the neighbouring frame, and some groups come out with one frame fewer
  than the header states (blink 3 instead of 4 in 5 rows; bounce 5/6 in 3 rows; cheer 5/6 in 6
  rows). Idle (6) and serve-ready (4) are complete for all 9 foods. Fix by hand-editing those frames
  or adding `boxes` regions in the config.
- **Sheet 12 (living foods A)**: all 10 foods x idle 4 / blink 4 / bounce 4 / cheer 3 / serve-ready 2.
  A handful of adjacent frames overlap in the source (e.g. ramen idle f01/f02, bao idle f02/f03,
  mochi bounce) and carry a sliver of the neighbour.
- **Sheet 18**: impatient and celebrate groups genuinely have 2 frames in the source (others 3).
- **Sheet 15 path tiles**: the source captions sit directly under the tiles; they are masked via
  `label_rects`, so the bottom few pixels of each path tile are trimmed where the caption touched.
- **Sheet 15 stepping_stone_04 / shrub_03 / rock_03** are small clusters of several stones; split
  manually if single stones are needed.
- **Sheet 16 petals/fx**: tiny loose petals and sparkle dots (min 10 px) are exported as
  `petal_loose_NN` and `petal_drift_fNN` / `sparkle_glow_fNN`; the frame order is reading order of
  the sheet and may need regrouping by an animator.
- **Sheet 4**: tiles are named per row (`tile_<row>_NN`) rather than per individual shape; some
  rows mix a full tile with edge/corner pieces (e.g. `tile_grass_blossom_06..09` are cliff edge
  pieces, `bridge_red_07/08` are posts).
- Labels in sheets 11–18 are detected heuristically; `_report.json` lists the count removed per sheet.
  Spot-checked contact sheets: 01, 02, 04, 05, 06, 07, 08, 09, 10, 13, 14, 15, 16, 17, 18 — no
  label text visible in exported sprites.
