# Ring Revolution v1.4.0

- 25 achievements with unique custom illustrations, progress tracking and retroactive unlocks for existing saves.
- Layered animated start screen and UI polish across menus, maps, gameplay controls, shop, Premium and utility screens.
- 280 translated strings and all 15 chapter names in English, Spanish, Brazilian Portuguese, German, French, Japanese, Korean, Hindi, Indonesian and Arabic; Dutch retained.
- Live AdMob rewarded/interstitial ads configured with the owner units, UMP consent handling and ad caps. Banners remain disabled. Debug builds keep ads off and use test IDs.
- Prepared Google Play Games achievements, two leaderboards and explicit cloud backup/restore with conflict selection.
- Play Billing 8 integration for the one-time Premium product, purchase-signature validation, acknowledgement and restore.
- Android API 36 target and privacy-policy link: https://www.shiostudios.com/privacy-policy

## Downloads

- **debug.apk**: installable debug build; ads disabled.
- **release.apk / release.aab**: minified release builds using live ad units. Check the attached **SIGNING-STATUS.txt** before use; signing depends on the configured repository keystore secrets.
- **console-setup.zip**: all 25 achievement PNGs, Premium artwork, localized achievement reference, owner IDs and configuration guide.

## Validation

Core and Android tests, all-achievement artwork rendering, Arabic narrow-screen renders, lint, debug APK and release AAB build passed on the feature commit. All 150 levels passed 2,783 checks with zero failures. The release workflow reruns verification before publishing and checks the actual generated release BuildConfig for live owner ad units.

## Configuration still required

Play Games features and purchases remain disabled unless their Play Console IDs and billing public key are configured. Live service flows still need device testing. No Play Store upload is performed by this GitHub release. Translations have not had native-speaker review.
