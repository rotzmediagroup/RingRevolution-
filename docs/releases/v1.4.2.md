# Ring Revolution v1.4.2 — Lantern Festival

A warmer, more playful celebration inspired by the supplied visual references.

- Bespoke sunset festival courtyard with lanterns, blossoms and glowing food stalls, used on the start screen and first-world gameplay.
- Bouncing dumpling host, moving layered background and brighter peach/gold utility screens.
- Colorful, finite confetti celebration when a level is completed. Reduce Motion and low effects quality disable confetti.
- Original 124 BPM instrumental synth-pop loop with K-pop influences: bright plucks, syncopated bass, pop drums and a catchy original hook. No sampled songs or licensed commercial recordings.
- Live owner AdMob IDs in both APK variants; adaptive menu banner added for non-premium players after consent. Banner loads reserve no empty space on failure. No banner overlays the game board.
- Rewarded offer reacts to consent changes. Failed fullscreen loads are retried while the app is in the foreground.
- Fixed sideload signing: the workflow creates an explicit temporary key and verifies the optimized APK signature.

## Downloads

Install **RingRevolution-v1.4.2-release-sideload.apk** for the optimized direct-install build when no owner keystore is configured. The debug APK also uses live advertising. Both APKs use the same temporary certificate within this workflow run.

These sideload APKs are not suitable for Play upload. The release AAB requires signing with the owner upload key. With owner repository signing secrets configured, the workflow produces an owner-signed release APK instead.

Tests and build checks do not verify actual live ad impressions on a physical device. Ad delivery still depends on consent, AdMob approval and available inventory.
