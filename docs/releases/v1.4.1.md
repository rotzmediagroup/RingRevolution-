# Ring Revolution v1.4.1

Both downloadable APKs now enable live AdMob with the owner rewarded, interstitial and banner unit configuration. The previous debug APK disabled advertising regardless of that configuration.

- Install **release-sideload.apk** for the optimized release build when no owner signing keystore is configured. It is signed with the CI debug certificate so Android can install it; it is not suitable for Play upload.
- **debug.apk** also uses live ads.
- The **release.aab** still requires the owner upload signing key before Play Console upload. When repository signing secrets are configured, the workflow produces an owner-signed release APK instead.
- Existing placements remain unchanged: rewarded ads are optional, interstitials start after the introductory levels and first session, and banner placement is not enabled.

Live ad delivery depends on consent and AdMob availability. No device impression has been verified by CI.
